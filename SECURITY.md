# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| 3.1.x | :white_check_mark: |
| 3.0.x | :white_check_mark: |
| < 3.0 | :x: |

Security fixes for **3.2.0+** apply to the full published set (`appdimens-dynamic`, strategy modules, and `appdimens-dynamic-bom`) at the shared version line.

## Reporting a Vulnerability

Please report security issues privately via GitHub Security Advisories on [bodenberg/appdimens-dynamic](https://github.com/bodenberg/appdimens-dynamic), or email the maintainer listed in the Maven POM (`jean.bodenberg2@outlook.com`).

You can expect an initial acknowledgement within a few days. If the report is accepted, a fix will be prepared for the supported 3.x line and credited as appropriate. If declined, we will explain why.
